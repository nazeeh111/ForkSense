# Changelog

## 0.1.0

Initial research preview.

- CLI workflow for environment inspection, structured planning, plan review, bounded experiments, offline reports and separate patch acceptance.
- Explicit causal hypotheses, cost-sensitive information-gain scheduling and inspectable evidence updates.
- Detached Git worktrees, source-path checks, fresh candidate verification, external verifier hash records, retained failed attempts and hash-checked acceptance.
- Documented Codex execution adapter and optional locally unverified Claude Code adapter; no hidden model-state access or permission bypass.
- No-account prepared-patch demo, a recorded live Codex fixture repair and original report/brand/media assets.
- Corrected, source-hashed live Flask pilot with repeated ordinary Codex comparison, withheld official tests, invalid-harness history and an explicit null improvement result.
- Frozen controlled benchmark with 630 trials, concurrent prepared-repair baseline, raw receipts, family-cluster intervals and an exploratory learned cost model.

The controlled adaptive policy matched fixed-three resolution with fewer commands. Learned cost ranking did not outperform the heuristic. Broad agent improvement, learned optimal stopping, full external tree-search comparisons and a SWE-bench score are not established by this release. See [known limits](docs/limitations.md).
